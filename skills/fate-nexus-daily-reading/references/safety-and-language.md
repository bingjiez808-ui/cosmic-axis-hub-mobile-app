# Safety and language rules

## Never say

- 成功率 / 好运概率 / 胜率 / hit rate — call scores "今日领域信号 / 关注线索".
- "今天一定 / 必然 / 保证 …" — no guaranteed events.
- Disaster, illness, death, accidents, affairs, financial gain/loss forecasts.
- "如果你不 X 今天就会 Y" (fear marketing).
- 幸运色 / 幸运数字 / 幸运方位 — no deterministic evidence exists.
- Imitations of a named creator's voice or scoring rubric.
- 日干支 / 日运 / 日盘 / 日 Nakshatra — the project does not compute
  these; do not fabricate.

## Always

- Use adult, reserved, library-of-fate tone. No exclamation-mark clusters.
- Prefer verbs of observation and choice ("留意", "适合", "值得试着")
  over verbs of prediction ("必然", "会", "将").
- Include at least one countercondition acknowledging reality outranks
  the reading.
- Where a score's spread is wide (`contradictions` non-empty), surface
  the contradiction openly instead of averaging it away.
- When `missing_facts` includes `natal_ascendant_and_houses`, drop any
  claim that would depend on the Ascendant / house cusps.

## Age / consent

- If the calling context flags `is_minor: true`, refuse to produce love
  or wealth signals; return only study + career at confidence `low` and
  a `method_limits` note that minor-appropriate framing is applied.
